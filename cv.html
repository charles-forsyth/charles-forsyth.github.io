AI and Research Platforms Built

  • ursa-bifrost (2026): MCP server and CLI in one Go binary that lets Claude, Gemini, Codex and other AI assistants work UCR's Slurm cluster through typed, audited, read-mostly tools; submit and cancel are opt-in with two-step approval and spend caps; per-user Google sign-in; hosted on Cloud Run. MIT licensed. github.com/UCR-Research-Computing/ursa-bifrost
  • UCR AI Gateway (2026): One governed OpenAI- and Anthropic-compatible endpoint to Gemini, Claude, open-weight and National Research Platform models, with per-lab budgets, per-key spend limits, rate limits, a full spend log and an admin MCP server.
  • Nexus (2026): The system of record for Research Computing's relationships: a Postgres and pgvector knowledge graph of researchers, labs, cloud projects, grants, tasks and interactions, run through a CLI and an OAuth MCP server with 41 role-gated tools.
  • Ursa Major HPC cluster on Google Cloud (2026): Elastic Slurm cluster built with Cluster Toolkit: compute created on demand and deleted when idle; CPU, high-memory and NVIDIA L4 GPU partitions; per-lab accounts and budget guardrails.
  • deep-research (2025-): CLI and web workstation for Gemini Deep Research that produces cited reports and checks their claims as real jobs on the HPC cluster. MIT licensed. github.com/charles-forsyth/deep-research
  • Ultra AI Workstation (2026): Keyboard-driven AI operator desk for email, calendar, tickets, Slack, the Nexus ledger and the cluster, with AI drafts under two-step approval. MIT licensed. github.com/charles-forsyth/ultra-workstation
  • Skywalker (2025-): Audit engine that scans hundreds of Google Cloud projects for security risk, idle and orphaned resources and AI spend; also a read-only MCP server. github.com/charles-forsyth/Skywalker
  • ursa-dsp (2026): Data Security Plan case tracker and assembler built with UCR's Information Security Office; people make every decision.
  • nrp-mcp (2026): Local MCP server for AI-assisted jobs on the NRP Nautilus GPU cluster, with NRP policy built in and single-use approval. Pilot.
  • UCR HPC Job Gallery (2026): 49 tested, standardized Slurm workflows across seven colleges and schools (including AlphaFold, from bioengineering to social science), with README, index and HTML gallery generated from the scripts. github.com/charles-forsyth/UCR-HPC-Job-Gallery
  • squad-manager (2026): Directed Agentic Engineering: orchestrates squads of specialized AI agents (architect, test writer, DevOps, developer, security gatekeeper, user acceptance) to design, build, test and release software. github.com/charles-forsyth/squad-manager
